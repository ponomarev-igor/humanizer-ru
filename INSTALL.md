# Humanizer RU: как установить и пользоваться

Это скилл для Claude Code. Он чистит русский текст от признаков нейросети: убирает штампы, канцелярит, длинное тире, «является», «в современном мире», переворотную риторику и прочее. На выходе текст звучит живее и по-человечески.

Скилл работает на твоей подписке Claude Code. Отдельный ключ и оплата не нужны.

## Что нужно

- Установленный Claude Code (CLI, расширение VS Code или приложение).
- Для скрипта количественной проверки (`scripts/check-prose-ru.py`) нужен Python 3, без внешних библиотек. Необязательно: скилл работает и без него, скрипт нужен только для точных цифр по длинному тексту.

## Установка

### Способ 1: git (рекомендуется, легко обновлять)

```bash
git clone https://github.com/ponomarev-igor/humanizer-ru.git ~/.claude/skills/humanizer-ru
```

Windows (PowerShell):

```powershell
git clone https://github.com/ponomarev-igor/humanizer-ru.git $env:USERPROFILE\.claude\skills\humanizer-ru
```

Обновление до новой версии: зайти в папку и `git pull`.

### Способ 2: без git

1. Скачай архив репозитория с GitHub (кнопка Code → Download ZIP) и распакуй. Внутри папка `humanizer-ru`.
2. Положи эту папку целиком сюда:
   - macOS / Linux: `~/.claude/skills/`
   - Windows: `C:\Users\ИМЯ\.claude\skills\`
   Если папки `skills` нет, создай её.

### После установки

Перезапусти Claude Code. Должно получиться: `~/.claude/skills/humanizer-ru/SKILL.md`.

## Как пользоваться

Напиши в Claude Code:

> хуманизируй этот текст: <вставь текст>

или дай файл:

> убери из этого текста признаки AI

Скилл выдаст результат в три шага: черновик, разбор «что выдаёт AI», финал.

## Что это НЕ делает

По умолчанию скилл не пишет «твоим голосом», только убирает машинные признаки. Можно попросить подстроиться под свой стиль по образцам своих текстов («пиши как я»), но это отдельная команда, сама по себе не включается.
