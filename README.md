# Humanizer RU

> Тексты от нейросетей на русском выдают себя не английскими штампами, а канцеляритом. «Является», «в рамках реализации», «осуществление повышения качества» — вот что палит модель на русском в первую очередь. English-хуманайзеры это не ловят вообще.

Skill для Claude Code, который редактирует русский текст: убирает канцелярит, длинное тире, переворотную риторику («не X, а Y» и восемь её маскировок), воду инфостиля, кластеры метафор, штампы чат-бота. Не переписывает текст с нуля, не выдумывает факты, не меняет тон. Плюс отдельный слой вычитки орфографии и пунктуации.

## Почему не как остальные хуманайзеры

- **Канцелярит, а не англицизмы.** Языковое ядро построено на русской редакторской традиции (Нора Галь, «Слово живое и мёртвое»; Ильяхов и Сарычева, «Пиши, сокращай»), а не на переводе списков признаков ИИ-текста с английского.
- **Запрет по функции, не по строке.** Модель легко переодевает «не X, а Y» в «казалось бы, X, на деле Y» или разбивает на два предложения. Правило описывает сам приём (сначала подставить заблуждение, потом его снять), а не конкретную фразу.
- **Есть количественная проверка**, не только «на глаз»: `scripts/check-prose-ru.py` считает коэффициент вариации длины предложений, плотность союзов-связок, кластеры метафор, тире и переворотную риторику по regex. Ноль внешних зависимостей, чистый Python 3.
- **Отдельный корректорский слой.** Часть 8 это орфография и пунктуация по нормам, а не только стиль. Можно попросить только вычитать ошибки, не трогая формулировки.
- **Не выдумывает.** Если в исходнике не было даты, цифры или детали, скилл не подставляет их ради «конкретики» и не добавляет фальшивых точных деталей ради «живости».
- **Ловит копипаст из чат-ботов.** Технические хвосты вроде `oaicite:`, `turn0search0`, `grok_card://`, `[cite: N]` — прямое доказательство, что кусок скопирован без правки. Скилл убирает их и отдельно предупреждает об источнике.
- **Не выдумывает правку, если её не нужно.** Если текст уже живой, скилл так и говорит, вместо того чтобы находить проблему там, где её нет.
- **Голос по запросу, не по умолчанию.** Можно попросить подстроиться под свой стиль по образцам собственных текстов, но включается это только явной командой, не само.

## Пример

**До:**
> В современном мире использование нейросетей в маркетинге является по-настоящему уникальным инструментом, играющим ключевую роль в трансформации индустрии. Стоит отметить, что осуществление внедрения данных инновационных технологий обеспечивает повышение эффективности.

**После:**
> Нейросети в маркетинге ускоряют скучную часть. Не всё подряд. Стратегию точно нет.
>
> Они отлично делают черновики: заголовки, рассылки, карточки товаров. И так же отлично звучат убедительно, будучи пустыми.

Полный разбор этого примера, со списком того, что именно поймано, в `core/humanizer-ru.md`.

## Установка

Нужен установленный Claude Code (CLI, расширение VS Code или приложение).

```bash
git clone https://github.com/ponomarev-igor/humanizer-ru.git ~/.claude/skills/humanizer-ru
```

Или без git: скачай архив репозитория и распакуй содержимое в `~/.claude/skills/humanizer-ru` (Windows: `C:\Users\ИМЯ\.claude\skills\humanizer-ru`).

Перезапусти Claude Code. Подробности и разбор проблем — в [`INSTALL.md`](./INSTALL.md).

## Как пользоваться

Скилл активируется по триггерам в разговоре: «хуманизируй», «убери AI», «сделай человечнее», «почисти от штампов», «проверь пунктуацию», «исправь ошибки». Можно и явно:

```text
хуманизируй этот текст: <вставь текст>
```

Для текста от ~300 слов можно дополнительно прогнать количественную проверку:

```bash
python3 scripts/check-prose-ru.py текст.md
```

Скрипт только показывает форму (тире, переворотная риторика, ровный ритм предложений, кластеры метафор) и не решает за автора. Жёсткие срабатывания (тире, переворотная риторика) стоит поправить всегда, предупреждения — разобрать руками.

## Что это НЕ делает

Не пишет «твоим голосом» и не генерирует текст с нуля — это редактор, не автор. Не гарантирует, что текст пройдёт конкретный AI-детектор: цель — живой русский текст, а не обход конкретного алгоритма.

## Структура репозитория

| Файл | Что внутри |
|---|---|
| [`SKILL.md`](./SKILL.md) | Собранный файл скилла — то, что читает Claude Code. Между маркерами `BEGIN/END core` вшит `core/humanizer-ru.md`, руками эту часть не редактировать |
| [`core/humanizer-ru.md`](./core/humanizer-ru.md) | Источник правды: все восемь частей правил, словарь клише, полный пример, процесс работы |
| [`scripts/check-prose-ru.py`](./scripts/check-prose-ru.py) | Количественная проверка прозы: коэффициент вариации длины предложений, плотность союзов, кластеры метафор, тире, переворотная риторика |
| [`scripts/build-skill.mjs`](./scripts/build-skill.mjs) | Вшивает `core/humanizer-ru.md` в `SKILL.md`. Запуск: `node scripts/build-skill.mjs` |
| [`INSTALL.md`](./INSTALL.md) | Подробная установка и что делать, если скилл не подхватился |
| [`CHANGELOG.md`](./CHANGELOG.md) | История версий |

## Разработка

Правки вносятся только в `core/humanizer-ru.md`, не в `SKILL.md` напрямую — файл пересобирается:

```bash
node scripts/build-skill.mjs
```

## Обратная связь

Нашёл ложное срабатывание, недостающий паттерн канцелярита или ошибку в правилах пунктуации — заведи Issue. Приложи пример текста до и после, это ускоряет разбор.
